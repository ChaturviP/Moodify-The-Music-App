# Moodify 🎵

Moodify is a Spotify-inspired Android music streaming and playlist management application built using Kotlin, Firebase Authentication, and modern Material Design principles.

The project focuses on delivering a clean, immersive, and user-friendly music experience through playlist handling, favourites tracking, recently played history, authentication flow, and polished streaming-style UI/UX design.

---

## 🚀 Features

- 🔐 Firebase Authentication (Login & Signup)
- 🎶 Playlist Creation & Management
- ❤️ Favourite Songs System
- 🕒 Recently Played Tracking
- 🎧 Interactive Music Player UI
- 👤 User Profile Management
- 📱 Modern Material Design Interface
- 🔄 Smooth Multi-Screen Navigation
- 📂 RecyclerView-based Dynamic Content Rendering
